What is a VANET?

Vehicular Ad-hoc Network (VANET)

A VANET is a specialized type of Mobile Ad-hoc Network (MANET) where vehicles communicate with each other (V2V) and with roadside infrastructure (V2I). This communication enables:

  • 📡 Real-time traffic information sharing
  • ⚠️ Safety warnings (accidents, hazards)
  • 🚦 Smart traffic management
  • 🗺️ Cooperative navigation

🔑 Key Parameters

  • Beacon Frequency (Hz): How often vehicles broadcast their status
  • TX Power (dBm): Transmission power affecting communication range

📊 Performance Metrics

  • PDR: Packet Delivery Ratio - success rate of message delivery
  • Throughput: Amount of data successfully transmitted
  • CBR: Channel Busy Ratio - network congestion level

🎯 Optimization Goal

  • High PDR: Reliable communication
  • High Throughput: Efficient data transfer
  • Low CBR: Reduced congestion

🤖 How Reinforcement Learning Optimizes VANET

The Challenge

Finding the optimal balance between BeaconHz and TxPower is complex because:

  • Network conditions change dynamically (vehicle density, speed, environment)
  • Trade-offs exist between reliability, throughput, and congestion
  • Static configurations can't adapt to changing scenarios

The RL Solution

Our RL agents (PPO & DQN) learn to:

  • 🎯 Observe network state (PDR, throughput, CBR, neighbors)
  • 🧠 Learn optimal policies through trial and error
  • ⚡ Adapt BeaconHz and TxPower in real-time
  • 📈 Maximize PDR and throughput while minimizing CBR

🎮 State Space

  • Current PDR
  • Throughput
  • CBR level
  • Number of neighbors
  • Current BeaconHz
  • Current TxPower

🎯 Action Space

  • BeaconHz: 4-12 Hz
  • TxPower: 15-30 dBm
  • 30 possible combinations

🏆 Reward Function

  • +Reward for high PDR
  • +Reward for high throughput
  • -Penalty for high CBR
  • -Penalty for excessive power
